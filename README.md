# hxyfront-62010 充填泵冷却水联动台

源提示词编号：5

在潜水气瓶充填记录基础上扩展为**充填泵冷却水联动台**。每个待充任务绑定泵编号、冷却水温度、流量与滤芯更换日，泵判定、任务落盘与页面呈现三层分离；刷新后工位、待检清单和设备履历保持一致（localStorage 持久化）。

## 联动规则

- **建档预检**：水温 > 35℃、流量 < 6L/min 或滤芯超期（更换日 + 额定天数 < 今天）任一命中，任务只进「设备待检」，不能占用充填位；合格才进待充填队列。
- **占工位**：一泵一位，上位前按泵实时读数再判一次，越线则退回待检。
- **越线暂停**：充填中可勾选越线项暂停，自动结算本段已用时长并记录当前压力。
- **双人复核续充**：暂停处理后须由另一人（≠ 操作员）复核，续充另起一段、时长单独累加。
- **签收双核实测**：实测压力须在目标 ±5%、氧浓度与目标相差 ≤ 1 个百分点，任一越限自动转返工；返工重新派发后重新预检、重新计时。
- **设备履历**：建档/拦截/复检/占工位/暂停/续充/完成/签收/返工/泵参数改动全部留痕，可按泵筛选；支持按气瓶编号查单瓶历史。

## 结构

```
src/domain/    泵判定纯函数 (rules.ts) + 落盘与种子数据 (storage.ts) + 类型
src/state/     useConsole：任务状态机与履历追加
src/components 页面呈现：工位 / 待检队列 / 签收 / 履历
```
