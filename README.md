# hxyfront-62010 充填泵冷却水联动台

潜水店气瓶充填前端：在原气瓶充填记录基础上，扩展为**充填泵冷却水联动台**。

## 业务规则

- 每个待充任务绑定一台泵，并记录冷却水温度、流量与滤芯更换日。
- **入台判定**：冷却水温度 **> 35℃**、流量 **< 6 L/min** 或滤芯超过更换周期（默认 180
  天），任一成立，任务只进「设备待检」清单，**不能占用充填位**。
- **充填中越线**：每秒巡检泵状态，任一参数越线立即自动暂停（也可人工紧急暂停），
  暂停瞬间冻结并记录**已用时长**与**当前压力**。
- **复核后续充**：暂停任务必须由与暂停操作人不同的另一人复核、且泵已恢复合格后续充；
  **续充时间单独累加为一段**，与首充分开显示和留痕。
- **签收前核实**：录入实测压力（目标 ±5 bar）与氧浓度（目标 ±1%），任一越限自动转返工；
  返工处理完可重新回到待充填队列。
- 设备履历只追加：建单、入台拦截、开充、越线/人工暂停、复判、复核续充、到压、签收、
  签收越限、返工回流、换滤芯、泵读数变更全部留痕。

## 三层结构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 泵判定（纯逻辑） | `src/domain/types.ts` | 阈值、`judgePump`、`judgeSignoff`、日期/时长工具，无 React 依赖 |
| 任务落盘 | `src/state/ConsoleContext.tsx` | reducer 状态机 + `localStorage` 持久化（任务/泵/履历分键、带版本号） |
| 页面呈现 | `src/components/*`、`src/App.tsx` | 泵台、表单、工位、队列/待检、签收返工、履历 |

刷新页面后，充填工位、设备待检清单与设备履历从同一份落盘状态恢复，保持一致；
页脚「恢复演示数据」可重置为内置种子。
